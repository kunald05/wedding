# Saumya & Kunal — Wedding Microsite

A no-passcode, mobile-first wedding microsite with a ceremonial physical-invitation opening.

## Personalized guest name

Append a guest name to the URL:

`?to=Shri%20and%20Smt.%20Sharma`

The guest name is rendered directly over the invitation artwork in the opening cover, styled to look printed/inked onto the card rather than placed in a separate plaque.

## Deploy

Upload the contents of this folder to GitHub Pages (or any static hosting provider). No build step or server is required.
